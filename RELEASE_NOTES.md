# RatioForge 1.1.0

RatioForge is now a cross-platform .NET 10 desktop application built with Avalonia UI.

- Native releases for Windows x64, Linux x64, macOS Intel, and macOS Apple Silicon
- Self-contained and lightweight framework-dependent executables for every platform
- Portable torrent parsing and HTTP(S) tracker announce engine
- HTTP and HTTPS tracker connections over IPv4 and IPv6, including literal `[IPv6]` tracker URLs
- SHA256 verification files for every release package

The Lite executable requires the .NET 10 Runtime for the matching platform. The standard executable and archive are self-contained.
